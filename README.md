# Dynamic Background Page — JavaScript & Ajax

A responsive web application featuring a dynamic background slider built with JavaScript and Ajax. Users can toggle between Day Mode, Night Mode, and Color Mode, each rendering a distinct gradient theme through asynchronous background updates without page reloads.

## Features
- Dynamic background transitions via Ajax
- Day/Night/Color mode toggle
- JavaScript slider animation
- Responsive full-screen layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Ajax

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Use the mode toggle buttons to switch between themes
